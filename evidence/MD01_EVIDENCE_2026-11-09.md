## 2. 契約落實要點

- **API：** `session.onAgentToolEvent(listener)`，可多次註冊、各自 unsubscribe；不取代 `onTool`。事件 deep-frozen、可 JSON 序列化、無 transport/handle。
- **Lifecycle：** `started → updated* → finished`；同 native id 重複通知合併；不同 Turn／Session 絕不合併；無 native id → 獨立紀錄＋`partial`；只有 finished → 保留＋`partial`；turn 結束／crash／fault／close 時仍開啟者 → `finished/unknown`（`TOOL_RESULT_NOT_OBSERVED`/`WORKER_CRASHED`/`SESSION_FAULTED`/`SESSION_CLOSED`），**不把 Turn terminal 灌給 Tool**；之後才到的 Provider 結果以 `lateObservation: true` 回報一次。
- **不杜撰：** `exitCode` 只填 Provider 明確數值；Claude Bash、Cursor 不提供 → `unavailable: ['exitCode']`。Codex `aggregatedOutput` 為合併串流 → `combinedStreams: true`＋`unavailable: ['stdout','stderr']`。
- **Native ↔ Host 關聯：** 只有「同 Turn 恰好一個 native Shell 呼叫寫了 `pedelec-cli … tool-call <同名> '<完全相同 JSON args>'`」才填 `parentToolCallId`（`correlation: 'command-match'`）；多個 → `ambiguous`、無 → `unlinked`；**從不用時間接近**。Native 事件列出 `hostInvocations`（tool-call/tool-spec）供 Host 以一個業務步驟計數；`tool-spec` 不產生 Host 事件。Host 先到、native 後到時以後續 `updated` 補上關聯。
- **Handler 結果 ≠ Provider 收到：** Host `finished.output.delivery = 'cli-reply-written'`、`providerAcknowledgement = 'unavailable'`。
- **Coverage：** 非 `supported` 的 Session 每個 Turn 開頭發 `observation-gap`（`PROVIDER_TRACE_UNSUPPORTED`／`PROVIDER_TRACE_COVERAGE_UNKNOWN`），沉默不等於零工具。
- **Bounded async：** 事件在 ingress 先清洗、凍結，再進**每 Listener 獨立**的 256 筆佇列；listener 永不在 Session 呼叫堆疊中同步執行；promise 最多等 10 s；滿載時計數，並在原位置插入一筆 `LISTENER_QUEUE_OVERFLOW` gap（含 `droppedEvents`、`droppedSequences`）。每事件有 Session 內遞增 `sequence`。
- **Redaction／上限（測試鎖定）：** command 4 KiB、一般字串 4 KiB、stdout 8 KiB、stderr 8 KiB、input 16 KiB、output 24 KiB、event 64 KiB；截斷尾綴 `…[truncated N bytes]`＋`detailTruncated`；敏感 key（數值計數除外）、Authorization/Cookie header、Bearer/Basic、URL 帳密、敏感 query、敏感環境變數與 CLI flag、OpenAI/GitHub/Slack/AWS/Google/npm/JWT token、PEM 私鑰 → `[REDACTED]`；workdir → `<workdir>`、home → `~`、他人 home → `/Users/<user>`、`C:\Users\<user>`。
