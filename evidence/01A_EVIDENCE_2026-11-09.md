## 7. 剩餘問題／風險

1. **Gate B 範圍有限：** 只有 macOS Codex／Claude 真跑；OpenCode、Cursor 未安裝；Windows／Linux 需真機或 CI；Antigravity 真 agy 本次未跑（且協定上仍 BLOCKED）。
2. **Consumer 責任轉移：** 移除 Redaction 後，Trace 事件可能含真 Token／Credential／私有路徑。目前 Pathcraft Host 尚未接線（MD02 範圍），接線時 Host 必須自行處理 ACL、UI/API 脫敏、Log、持久化與 Retention。
3. **故障注入只在 debug build：** `PEDELEC_TOOL_TRACE_FAULT` 於 release build 不編入；release 的隔離依賴相同程式路徑（`trace()` 無回傳錯誤），未在 release binary 上做注入。
4. **共享 IPC writer 真損壞：** 依設計由下一筆主業務 emit 觸發既有 Fault；若 Provider 長時間只產生 trace 而無業務 frame，fault 偵測會延後到下一個業務事件（不會假裝成功）。
5. **Host parent 關聯消失：** MD01 的 `command-match` 已移除；若日後需要 Native Shell ↔ Host 父子，需在 `pedelec-cli` 協定加入可信 parent／invocation id（需另開需求，可能觸及 MD02）。
6. **Bun 回歸 NOT RUN：** `test:bun`、`test:sdk:bun` 本機無 Bun；Server 消費者以 vitest 代跑之 9 個失敗與 HEAD 基準相同。
7. **Fixture 非真擷取：** Codex／OpenCode／Cursor fixture 仍為依協定撰寫（Codex 真跑已確認 `commandExecution`／`mcpToolCall` 欄位映射正確）。
